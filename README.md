# mannheim-feed

A feed repository for Mannheim data and content.

Lector personal de noticias de Mannheim: una app (PWA) para móvil y laptop, un recolector de noticias por RSS y una base de datos en Supabase.
Lee la guía completa en [GUIA.md](GUIA.md).

**Diseño / Design:** los colores, tipografía y espacios viven como *tokens* en [design-system/](design-system/README.md) (guide in English). Vista previa: `design-system/dist/preview.html`.
